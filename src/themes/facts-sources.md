# Theme facts – sources for fact-checking

Every `Fact` shown on the win/home screen, with the exact claim text and the
source to verify it against. Generated from `allThemes()` in `calendar.ts` –
if you change a fact there, update this table.

Rules the facts were written to:
- Only claims the author was confident are true; hedged wording ("traditionally",
  "legend says", "one idea is") is used where the history itself is uncertain.
- Joke days (Lidl-ish Day, Vape Week) are labelled as made up and make no factual claim.
